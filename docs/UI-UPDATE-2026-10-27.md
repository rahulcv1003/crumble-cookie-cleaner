# Interface update — Crumble 0.2.0

27 October 2026. The owner requested a premium feel, typography improvements,
and explanations that help people choose settings with confidence.

## What changed

- Redesigned popup, settings, setup and confirmation dialogs with a quieter
  canvas, rounded surfaces, fine borders, restrained shadows and clearer hierarchy.
- Bundled the unmodified Inter 4.1 variable font locally. It works offline;
  the full SIL Open Font License ships in the package.
- Refined light and dark palettes, original navigation icons, visible keyboard
  focus and reduced-motion support.
- Added contextual help for list choices, automatic cleaning, delays, startup,
  embedded cookies, site-data options, import/export, cleanup and Undo.
- Help works on hover, keyboard focus and dedicated tap targets. It can be
  dismissed with Escape and stays inside the window. Opening help never runs
  cleanup or changes a setting.
- Corrected the open-tabs confirmation to distinguish the two-minute cookie
  Undo window from site data, which cannot be restored.
- Refreshed documentation, interface captures, store artwork and the website's
  popup preview. The package version is now 0.2.0.

Cleanup rules, defaults, stored data format, permissions and the background
cleanup engine retain their existing behaviour. The updated font is the only
new third-party runtime asset.

## Inspiration and thanks

Apple's attention to typography, spacing and restrained visual hierarchy was a
design reference for this update. Crumble uses its own components and identity;
no Apple logo, proprietary font or artwork is bundled, and no affiliation is implied.

Thank you to the [Cookie AutoDelete](https://github.com/Cookie-AutoDelete/Cookie-AutoDelete)
contributors for the original cookie-cleaning workflow that inspired Crumble,
including list-based protection and import compatibility. This acknowledgement
remains in About, the README, the website and the store description.

Thank you to [Rasmus Andersson and the Inter contributors](https://rsms.me/inter/)
for making an excellent open font available. See `LICENSE-THIRD-PARTY.md` and
`assets/fonts/OFL.txt` for the licence.

## Review

The light/dark popup, settings and setup captures were visually inspected.
Automated coverage includes help persistence and dismissal, accessible
descriptions, no changes from reading help, local font loading, narrow-window
layout and axe accessibility checks in both themes. Final counts and limitations
are recorded in [test results](TEST-RESULTS.md).

Use [the final Chrome checklist](../FINAL-TEST.md) for real-profile acceptance
before submitting the store draft. Automated Chromium coverage does not replace
Chrome Web Store review or a person checking screen-reader and touch behaviour.
